Season Snow Logic:
- Only care for global weather, local weather comes later.
- We only care for Winter / No Winter. Temperature changes -0.7 in winter.
- Each unloaded chunk saves the global world time it got last modified
- Snow/Thaw is done by a pseudo random pattern. Each chunk gets a number from 1 - X ticks, defining the time from start of snow till this block gets snowed on / thawed. This pattern is repeated forever to set / remove snow.
- Patterns for loaded chunks are saved and updated every tick. Snows / Thaws as needed
- Global list for snowEvents, contains start global world time and end time. When starting snowing, put event in. When stops snowing (or season changes), set end. Max 10.
- Global list for thawEvent, contains start global world time and end time. When season changes, put event in.
- On loading chunk, check last modified time against snow/thaw list:
    - First get last snow / thaw tick, and if there was a snow event (even in summer)
    - For that, go through the list and find the latest full list. if found, we can start here and set all timestamsp to that
    - Then go through the events one by one and check if there was a later event, update timestamp accordingly
    - Lastly, also process snow events in summe - but put into separate array (For perma snow)

DH Logic:
- Keep [max lod distance * max lod distance] array clientside
- Sync snowEvents/thawingStart to client on connect or dimension change, client keeps updating it
- LOD chunk needs last modified time as well
- if season changes or dimension changes, put all in unknown list.
- if at least one block in chunk can thaw, put in thaw list.
- if at least one block in chunk can snow, put in snow list.
- if snow ends put all from snow list into snowpostprocess list, where they are removed once processed. only removed from snow once fully snowed
- on season change clear thaw/snow list
- remove from lists if fully processed
- Have list to check if block should be
- Update lists on movement, queue new blocks, remove old ones
- Mark ~200 DH chunks second for render update. They check if there should be snow, and add/remove it accordingly.
